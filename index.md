## [Software](software/)
**Full list on the [software page](software/).** Recent highlights include:

- [mm2gpsd](https://github.com/Jachimo/mm2gpsd) — Exposes GPS data
  from ModemManager-supported LTE modules to `gpsd` via a pseudo-serial
  interface.  Useful for Panasonic Toughpads with integrated GPS.
- [transcriber](https://github.com/Jachimo/transcriber) - Python
  wrapper for transcribing voice recordings with various
  speech-to-text models. Produces Obsidian-style structured text.
- [chatlogtoeml](https://github.com/Jachimo/chatlogtoeml) — Conversion
  utility to migrate various types of chat (instant message) logs to
  RFC822 .eml files for archiving.
- [experiments](https://github.com/Jachimo/experiments) — Various
  small code experiments and utilities; irregularly updated.
