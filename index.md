## [Software](software/)

* [Aperture Library Extractor](https://github.com/Jachimo/aplib-extractor) - Migrate images and metadata out of Apple Aperture Library format into plain files.
* [AppleDouble to XMP](https://github.com/Jachimo/experiments/tree/main/apple_metadata) - Convert Apple Finder metadata (AppleDouble "._" files) to XMP sidecars for DAM workflows.
* [Taky](https://github.com/Jachimo/taky) - Fork of tkuester's Python TAK server, with OCI Object Storage backend support.
* [CoT Tools](https://github.com/Jachimo/cot-tools) - Test utilities for the Cursor on Target (CoT) tactical data interchange format.
* [Obsidian Tagging Tools](https://github.com/Jachimo/obstagtools) - Batch tagging, filtered exports, and auto-tagging tools for Obsidian documents.
* [MBOX to CouchDB](https://github.com/Jachimo/mbox-to-couchdb) - Import email from a Unix MBOX file into CouchDB.
* [.eml to MBOX](https://github.com/Jachimo/emlToMbox) - Add individual .eml files to a new or existing Unix MBOX file.
* [MIME Wrapper](https://github.com/Jachimo/mimewrapper) - Wrap arbitrary files in RFC 2045 MIME format with custom headers.
* [Adium to .eml](https://github.com/Jachimo/adiumtoeml) - Convert Adium chat logs to MIME .eml files.
* [MBOX Deduplicator](https://github.com/Jachimo/mbox_dedupe) - Deduplicate MBOX files by Message-ID header.
* [Mailbox Lightener](https://github.com/Jachimo/mailbox_lightener) - Strip MBOX files down to plain text, discarding HTML and attachments.
* [iChat to .eml](https://github.com/Jachimo/ichat_to_eml) - Convert iChat conversations to MIME .eml files.
